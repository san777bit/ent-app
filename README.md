# ЕНТ | История искусств

Интерактивный тренажёр для подготовки к ЕНТ по истории искусств. Приложение позволяет проходить тесты по темам, пробный ЕНТ с выбором приоритетных тем и полный случайный тест.

## Возможности

- Практика по отдельным темам.
- Пробный ЕНТ с вопросами с одним и несколькими вариантами ответа.
- Ситуационные вопросы с иллюстрациями.
- Навигация по вопросам и просмотр результатов тестирования.

## Запуск локально

Это статическое веб-приложение, зависимости устанавливать не нужно. Из корневой папки проекта запустите локальный HTTP-сервер:

```sh
python -m http.server 8000
```

Откройте [http://localhost:8000](http://localhost:8000) в браузере.

## Структура проекта

- `index.html` — разметка приложения.
- `style.css` — стили и адаптивное оформление.
- `app.js` — логика тестирования и навигации.
- `questions.js` — база вопросов.
- `public/images/` — изображения для ситуационных вопросов.

## Публикация

Проект настроен для публикации на Vercel через файл `vercel.json` (`.vercel.json`).
